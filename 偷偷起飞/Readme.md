# 微量化系统

一个基于 baostock + 新浪财经实时接口的 A 股技术面选股工具。

没什么玄学，就是把平时看盘时会关注的那些技术信号（缩量、均线粘合、MACD 金叉、KDJ 位置……）写成代码，让它自动跑一遍全市场或者你自定义的股票池，把符合条件的票挑出来。再配合实时行情和持仓管理，做一个简单的操作建议参考。

------

## 这个项目是怎么来的

起因很简单：每天收盘后翻几千只票太累了。

一开始只是想写个脚本，把"地量 + 均线粘合 + 低点抬高"这些形态筛出来，看看有没有主升浪启动前的那种票。后来发现光有日线扫描不够用，盘中总想看看自己持仓的票技术面有没有变化，就又加了实时行情和技术指标研判。再后来持仓多了记不住成本，又加了持仓管理和实时建议。

慢慢就长成了现在这个样子。代码不算优雅，但能跑，对我来说够用。

## 主要功能

### 1. 全市场 / 分板块扫描

可以扫全市场，也可以只扫指定板块：

- 沪市主板（6 开头）
- 深市主板（0 开头）
- 创业板（3 开头）
- 北证（4/8 开头）

扫描的时候按板块过滤，避免每次都跑 5000 多只票干等。想扫哪个扫哪个，也可以自己拼组合，比如 `sh,cyb`。

### 2. 主升前夕信号检测

这是核心功能，检测 5 类信号，加权打分，满分 12 分：

| 信号     | 满分 | 判断依据                               |
| :------- | :--- | :------------------------------------- |
| 地量     | 3    | 当日成交量低于过去均量的 40% / 60%     |
| 均线粘合 | 3    | MA5/10/20/60 离散度低于 3% / 5%        |
| 形态收敛 | 3    | 近 20 日波动率与前期比值低于 0.5 / 0.7 |
| 低点抬高 | 2    | 最近 3 个局部低点依次抬高              |
| 低位     | 1    | 当前价处于 120 日区间下方 30% 以内     |

总分 ≥ 5 会被标记为"主升前夕"，扫描时再用你设的阈值（默认 8 分）二次过滤。阈值越高，选出来的票越少，信号越强。

### 3. 单只股票实时技术面研判

输入一个代码，程序会：

- 拉取近 250 个交易日的历史日线
- 用新浪财经的实时行情覆盖今天的 K 线
- 重新计算一整套技术指标
- 输出评分和操作建议

指标包括均线系统、MACD、KDJ、RSI、BOLL、量比、120 日位置等等。盘中随时可以看，不用等收盘。

### 4. 多票实时监控

可以输入一串代码，程序按你设的间隔（默认 60 秒）循环刷新，每一轮都重新拉实时价、重算指标、输出建议。

支持 Ctrl+C 随时退出。

### 5. 持仓管理

记录每只持仓的成本价和股数，存在本地 `positions.json`。程序会结合你的持仓状态和技术面评分，给出不同的操作建议：

- 空仓时：买入 / 建仓 / 关注 / 观望 / 回避
- 持仓时：加仓 / 持有 / 减仓 / 卖出，并且浮亏超过 8% 会优先提示止损

### 6. 定时日志

实时监控的每一轮结果都会自动写入 CSV 日志，支持：

- **按时间段切分**：每小时 / 每天 / 每周 / 每月换一个新文件
- **自定义文件名**：支持 `{date}`、`{hour}`、`{segment}`、`{code}` 等占位符
- **自动清理**：按留存天数 + 最多文件数双重限制，超期的自动删
- **配置持久化**：存在 `log_config.json`，下次启动直接读

日志是标准 CSV，列包括时间、代码、名称、现价、涨跌幅、评分、建议、浮盈、各技术指标值、判断依据等。可以直接用 Excel 或 pandas 打开复盘。

## 用到的库

| 库                                                   | 用途                           |
| :--------------------------------------------------- | :----------------------------- |
| `baostock`                                           | 历史日线数据（免费，无需注册） |
| `requests`                                           | 拉新浪财经实时行情             |
| `pandas` / `numpy`                                   | 数据处理和指标计算             |
| `csv` / `json`                                       | 日志和配置读写                 |
| 标准库 `re` / `os` / `time` / `datetime` / `pathlib` | 常规辅助                       |

实时行情用的是新浪的 `hq.sinajs.cn`，免费的，不需要 token，缺点是偶尔会抽风或者被限流。历史数据用 baostock，稳定但要记得控制请求频率，一次性扫全市场大约需要 15-30 分钟。

## 几个典型用法

### 只想找主升前夕的票

菜单 → `1`，选板块（比如创业板），扫描模式选测试或全量，阈值用默认 8 分。跑完后可以按评分筛选或者导出 CSV。

### 想看某只票现在能不能买

菜单 → `3`，输入代码，等几秒。程序会打印现价、涨跌幅、均线状态、MACD/KDJ 状态、RSI、BOLL、量比、120 日位置，然后给一个综合评分和操作建议。

### 想盯自己手上的票

先在菜单 `5` 把持仓录进去，然后菜单 `4` 输入要盯的代码，设定刷新间隔。程序会循环刷新，把每轮结果写到日志里。

### 想回看历史监控记录

日志默认在 `logs/` 目录下，按你设的命名规则生成 CSV。想改命名规则或者留存策略，进菜单 `8`。

## 文件结构

text

```
.
├── 偷偷起飞.py              # 主程序，所有逻辑都在里面

    ├── 20250921_14.csv
    ├── 20250921_15.csv
    └── ...
```

代码结构上分了几个模块：

- `StockAnalyzer`：baostock 登录、股票列表、历史 K 线拉取，带重试
- `RealtimeQuote`：新浪实时行情批量获取
- `TechnicalAnalyzer`：纯计算，输入 df 输出所有技术指标
- `StockAdvisor`：打分 + 操作建议
- `PositionManager`：持仓读写
- `PreMainRiseDetector`：主升前夕信号检测
- `AutoScanner`：全市场 / 自定义池扫描
- `RealtimeMonitor`：实时监控循环
- `LogManager`：日志写盘、切段、清理、配置持久化

## 一些细节上的说明

### 关于"实时"

严格来说这个项目不是"实时行情系统"。baostock 给的是日线数据，一般 T+1 才更新。所以做法是：

1. 拉最近 250 天的历史日线
2. 用新浪的实时价格覆盖最后一根（今天）的收盘价
3. 重新算所有指标

这样盘中看到的 MACD、KDJ 是动态变化的，不是昨天收盘的死数据。但因为是日线级别，指标变化不会像分钟线那么剧烈。

### 关于筹码集中度

代码里有个"筹码集中度"字段，注意它**不是**同花顺或通达信那种基于完整筹码分布模型算出来的。它只是一个简化指标：

> 最近 120 个交易日里，收盘价落在当前价 ±10% 区间内的成交量，占总成交量的比例。

参考可以，别当成真正的筹码分布来用。

### 关于接口稳定性

baostock 免费接口有频率限制，短时间内大量请求会被掐连接（表现为 `WinError 10053`）。代码里加了重试机制，遇到异常会等 1.5 秒重连一次，最多试 3 次。扫描时也有 `time.sleep` 控制节奏，尽量别把这个值调得太小。

### 关于日志清理

日志清理只在两种情况触发：

1. 每次切段（跨小时 / 跨天）时
2. 在菜单 `8` 里手动点"立即清理"

不会频繁扫盘。清理只删 `logs/` 目录下的 `.csv` 文件，其他文件不动。**不要把留存天数和最多文件数同时设成 0**，那样日志会无限堆积。

### 关于技术评分

单只股票的技术评分由 `StockAdvisor.score_technical` 生成，范围大致在 **-100 到 +100** 之间，实际能拿到的分数集中在 **-60 到 +90** 左右。

评分由 10 个维度加权加总，每个维度的具体规则如下：

| #    | 维度         | 条件                        | 分数 |
| :--- | :----------- | :-------------------------- | :--- |
| 1    | 均线排列     | MA5>MA10>MA20>MA60          | +20  |
|      |              | MA5<MA10<MA20<MA60          | -20  |
| 2    | 价格 vs MA20 | 现价 > MA20                 | +5   |
|      |              | 现价 ≤ MA20                 | -5   |
| 3    | MACD 交叉    | 今日金叉                    | +15  |
|      |              | 今日死叉                    | -15  |
| 4    | MACD DIF     | DIF > 0                     | +5   |
|      |              | DIF ≤ 0                     | -5   |
| 5    | KDJ 交叉     | 今日金叉且 K < 80           | +10  |
|      |              | 今日死叉                    | -10  |
| 6    | KDJ J 值     | J > 100                     | -5   |
|      |              | J < 0                       | +5   |
| 7    | RSI(14)      | RSI > 70                    | -10  |
|      |              | RSI < 30                    | +10  |
| 8    | 布林带       | 触及上轨                    | -10  |
|      |              | 触及下轨                    | +10  |
| 9    | 量能         | 放量上涨（量比>1.5 且收阳） | +10  |
|      |              | 放量下跌（量比>1.5 且收阴） | -10  |
| 10   | 120 日位置   | 低于区间 30%                | +10  |
|      |              | 高于区间 80%                | -10  |

分数对应的大致含义：

| 分数区间  | 含义               |
| :-------- | :----------------- |
| ≥ 60      | 多指标共振向好     |
| 40 ~ 60   | 技术面偏强         |
| 20 ~ 40   | 略偏强，信号不集中 |
| 0 ~ 20    | 中性               |
| -20 ~ 0   | 略偏弱             |
| -60 ~ -20 | 技术面偏弱         |
| ≤ -60     | 全面走弱           |

### 不同持仓状态下的操作阈值

**空仓：**

- ≥ 60：买入
- 40 ~ 60：建仓（小仓试探）
- 20 ~ 40：关注 / 轻仓
- 0 ~ 20：观望
- < 0：回避

**持仓：**

- 浮亏 ≤ -8%：止损卖出（最高优先级）
- ≥ 60：加仓 / 坚定持有
- 30 ~ 60：继续持有
- 0 ~ 30：减仓观望
- < 0：卖出
- 额外规则：120 日高位 + MACD 死叉 → 强制降级为减仓

### 使用建议

评分只是一个粗略的量化参考，不是买卖信号。程序输出的 `reasons` 字段里会列出每一项的具体加减分理由，看分数的时候建议同时看一下理由，理解分数背后的技术状态。

技术指标本身有滞后性，评分高不代表一定涨，评分低也不代表一定跌。是否操作，需要结合大盘环境、板块、基本面和自己的仓位综合判断。

## 后续可能加的东西

都是想法，不一定都做：

- **更多指标**：目前只有 MACD、KDJ、RSI、BOLL，后面想加 CCI、WR、OBV、DMI 这些
- **形态识别**：现在的"低点抬高"很粗糙，想加更完整的形态识别，比如三角形收敛、旗形整理、W 底这些
- **回测模块**：目前所有信号都是拍脑袋定的，想加一个简单的回测，看看历史上"主升前夕"信号触发后 20 天的胜率和平均收益
- **多数据源支持**：baostock 有时候确实不太稳，考虑加 tushare 或者其他源的接口
- **企业微信 / 钉钉推送**：盘中信号触发的时候直接推到手机，不用守着终端
- **GUI**：现在的命令行界面用久了确实不太方便，考虑用 PyQt 或者 Streamlit 做个简单的界面
- **板块热度**：结合行业板块和概念板块的资金流向，给信号加一层板块过滤
- **港美股支持**：现在的代码写死了 A 股前缀，扩展起来要做一些改动

有想法的可以直接改，代码结构不算复杂，基本都是独立模块。
